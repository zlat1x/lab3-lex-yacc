
# MiniC — Lex/Yacc-based Parser

Лабораторна робота №3 із системного програмування.

## Опис

MiniC — синтаксичний аналізатор підмножини мови C, реалізований за допомогою Flex та GNU Bison.

Програма виконує лексичний і синтаксичний аналіз, будує абстрактне синтаксичне дерево (AST) та інтерпретує його.

## Підтримувані конструкції

- Точка входу `int main()`
- Цілочисельні змінні та присвоєння
- Арифметичні й логічні вирази
- Оператори порівняння
- Умовні конструкції `if/else`
- Цикли `while`
- Вкладені блоки та області видимості
- `printf` для виведення цілих чисел
- Оператор `return`

## Використані технології

- C
- Flex
- GNU Bison (LALR(1))
- GCC
- GNU Make
- Python 3 (для автоматизованих тестів)

## Збирання

```bash
make
```

## Запуск

```bash
make run
```

Або для власного файлу:

```bash
./build/minic examples/demo.c
```

## Тестування

```bash
make test
```

Набір містить 11 тестів для перевірки коректного виконання програм та обробки помилок.

## Очищення

```bash
make clean
```

## Структура

- `src/` — лексер, граматика, AST та інтерпретатор
- `examples/` — приклади вхідних програм
- `tests/` — автоматизовані тести
- `Makefile` — автоматизація збирання

## Обмеження

MiniC реалізує навчальну підмножину C, а не повний стандарт мови.
