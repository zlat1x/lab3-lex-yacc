
# MiniC — Lex/Yacc-based Parser

Лабораторна робота №3 із системного програмування.

## Опис

MiniC — синтаксичний аналізатор підмножини мови C, реалізований за допомогою Flex та GNU Bison.

Програма виконує лексичний і синтаксичний аналіз, будує абстрактне синтаксичне дерево (AST), інтерпретує його, генерує Python-код та експортує дерево у формат JSON для інтерактивної візуалізації у веббраузері.

## Підтримувані конструкції

- Точка входу `int main()`
- Цілочисельні змінні та присвоєння
- Арифметичні й логічні вирази
- Оператори порівняння
- Умовні конструкції `if/else`
- Цикли `while`
- Вкладені блоки та області видимості
- `printf` для виведення цілих чисел
- Оператор `return`

## Використані технології

- C
- Flex
- GNU Bison (LALR(1))
- GCC
- GNU Make
- Python 3 (цільова мова трансляції та автоматизовані тести)
- HTML5 та CSS3 (вебінтерфейс візуалізатора)
- JavaScript та SVG (графічне відображення AST)

## Збирання

```bash
make
```

## Запуск

```bash
make run
```

Або для власного файлу:

```bash
./build/minic examples/demo.c
```

## Тестування

```bash
make test
```

Набір містить 29 автоматизованих тестів для перевірки синтаксичного аналізу, виконання програм, обробки помилок, генерації Python-коду та коректності JSON-представлення AST.

## Генерація Python-коду

MiniC підтримує трансляцію програм із реалізованої підмножини C у Python.

Для генерації коду з прикладу:

```bash
make generate
```

Результат зберігається у файлі `out/demo.py`.

Для запуску згенерованої програми:

```bash
python3 out/demo.py
```

Також можна вказати власний вхідний та вихідний файли:

```bash
./build/minic --emit-python examples/precedence.c out/precedence.py
```

Генератор використовує AST для побудови Python-коду. Допоміжні функції забезпечують підтримку областей видимості, цілочисельних операцій та перевірок помилок виконання.

Автоматизовані тести порівнюють результати інтерпретатора MiniC і згенерованих Python-програм.

## Експорт та візуалізація AST

MiniC дозволяє експортувати абстрактне синтаксичне дерево у формат JSON.

### Генерація JSON

```bash
make generate-ast
```

Результат зберігається у файлі `out/demo-ast.json`.

Для іншої вхідної програми:

```bash
./build/minic --emit-json examples/precedence.c out/precedence-ast.json
```

### Запуск вебвізуалізатора

У кореневій папці проєкту запустити локальний HTTP-сервер:

```bash
python3 -m http.server 8000
```

У браузері відкрити:

http://localhost:8000/viewer/

Для зупинення сервера натиснути `Ctrl + C`.

### Можливості AST Viewer

- Автоматичне завантаження стандартного AST.
- Завантаження власних JSON-файлів.
- Інтерактивне відображення дерева засобами JavaScript та SVG.
- Розгортання та згортання гілок дерева.
- Масштабування та переміщення дерева.
- Перегляд інформації про вибраний вузол.
- Виділення типів вузлів різними кольорами.

Візуалізатор не потребує сторонніх JavaScript-бібліотек.

## Очищення

```bash
make clean
```

Команда видаляє каталог `build/` із результатами компіляції. Згенеровані файли в каталозі `out/` залишаються без змін.

## Структура

- `src/` — Flex-лексер, Bison-граматика, AST, інтерпретатор, генератор Python та JSON-експорт
- `examples/` — приклади правильних і некоректних програм
- `tests/` — 29 автоматизованих тестів
- `viewer/` — інтерактивний вебвізуалізатор AST
- `Makefile` — автоматизація збирання, запуску та тестування
- `build/` — згенеровані файли й виконувана програма (створюється автоматично)
- `out/` — результати генерації Python та JSON (створюється за потреби)

## Обмеження

MiniC реалізує навчальну підмножину C, а не повний стандарт мови.
